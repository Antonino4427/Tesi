You've just downloaded our Unity integrations.

This zip archive contains two Unity packages. The first is our bespoke Unity plugin. This plugin interfaces with MANUS Core directly.
It contains hand models that are optimised for working with our data, functionality to set up custom hand models to work with our system and an interaction system that includes integration with our haptic functionality.
For more information see https://docs.manus-meta.com/latest/Plugins/Unity/

Alternatively, our gloves can also be used through OpenXR. MANUS Core integrates natively with the OpenXR Hand Tracking extension. 
OpenXR does not currently support finger haptics natively thus we have created our own custom solution to enable finger haptics with MANUS gloves.```
Making use of this functionality requires the OpenXRUnityHaptics Unity package. When not using haptics this package is not necessary.
For more information see https://docs.manus-meta.com/latest/Plugins/OpenXR/
